# Yogishift

Yogishift est mon projet de fin d’année.  
L’objectif est de créer une plateforme autour du yoga permettant de consulter des offres, connecter des studios et des professeurs, et gérer des interactions comme dans une application métier réelle.

Ce projet m’a permis de travailler sur une architecture complète avec un frontend, un backend et une base de données, dans un environnement proche de la production.

---

##  Stack technique

- **Frontend** : React + Vite  
- **Backend** : Node.js (Express)  
- **Base de données** : MySQL  
- **Environnement** : Docker (multi-services)

L’ensemble est orchestré avec Docker Compose pour garantir un environnement de développement reproductible.

---

##  Objectifs du projet

- Mettre en place une architecture **full-stack claire (front / back / DB)**
- Créer une API REST avec Node.js
- Connecter le frontend à une API réelle
- Structurer proprement un projet comme en entreprise
- Utiliser Docker pour standardiser l’environnement
